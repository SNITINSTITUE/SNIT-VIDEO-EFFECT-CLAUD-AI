# SNIT 58 Pro Motion Graphics & Video Effects Skill

When the user activates this skill or asks to apply a video/motion effect to an uploaded photo or video clip:

1. **Identify the Requested Effect:** Match the user's request to one of the 58 SNIT presets below (if unspecified, suggest 3 matching presets or default to `06-cyber-matrix` / `09-kinetic-slam`).
2. **Build a Full-Height 9:16 Interactive Motion Artifact:**
   - Render a responsive `9:16` (`1080x1920` aspect ratio) self-contained HTML/CSS/JS Artifact embedding the user's uploaded image or video.
   - Use hardware-accelerated CSS `@keyframes`, SVG path animations, and Canvas particle/HUD layers running at smooth 60fps.
   - Include a subtle floating control bar at the bottom (hidden during full-screen playback) with **Replay Animation**, **Edit Headline/Text**, and **Toggle Aspect (9:16 / 16:9)** controls.
